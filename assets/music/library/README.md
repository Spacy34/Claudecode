# Bibliothèque musicale (vos morceaux libres de droits)

Rangez vos musiques dans un sous-dossier par ambiance : `comique/`, `calme/`, `tension/`, `triste/`,
`romantique/`, `epique/`, `bizarre/` (formats : .mp3, .wav, .m4a, .ogg, .flac).
Le studio choisit automatiquement un morceau selon le ton de l'épisode (stable d'un rendu à l'autre), le baisse
sous la voix (ducking), le normalise et le fait disparaître en fondu à la fin. Ambiance forcée par épisode :
tableau de bord → Voix & sons.

**Licence (obligatoire pour publier)** : n'ajoutez que des morceaux dont la licence autorise l'usage commercial
sur les réseaux sociaux, et consignez-la à côté du fichier : `mon_morceau.mp3.licence.txt` (source, auteur,
licence, lien). Le tableau de bord le fait pour vous à l'ajout. Sans ce fichier, la livraison indique
« licence non consignée ».

Les fichiers audio de ce dossier ne sont pas versionnés (git) : ils restent sur votre machine.
